# SiliQunLib Checkpoint Data

This directory stores the 50 pre-trained primitive gate policy checkpoints
for SiliQunLib.

## File format

Each checkpoint is stored as a NumPy `.npz` file (hardware-agnostic) with
optional PyTorch `.pt` companion files for faster loading when PyTorch is
installed.

### `.npz` schema

| Key | Shape | Description |
|-----|-------|-------------|
| `fc1.weight` | `(h1, obs_dim)` | First hidden layer weights |
| `fc1.bias`   | `(h1,)` | First hidden layer biases |
| `fc2.weight` | `(h2, h1)` | Second hidden layer weights |
| `fc2.bias`   | `(h2,)` | Second hidden layer biases |
| `fc3.weight` | `(action_dim, h2)` | Output layer weights |
| `fc3.bias`   | `(action_dim,)` | Output layer biases |

All arrays are `float32`.

## Downloading checkpoints

Checkpoints are generated by the QUASAR v19/v27 training runs on Aziz HPC
and the local GPU. To populate this directory, run:

```bash
python -m siliqun.library.tools.export_checkpoints \
    --results-dir /path/to/quasar_v19/results \
    --output-dir siliqun/library/data
```

If no checkpoint files are present, `PrimitiveLibrary` will return
synthetic (random-weight) placeholder policies with a warning.
