# SoftwareX Journal Requirements Summary

## Key Facts
- Impact Factor: 2.4
- CiteScore: 4.2
- Open Access journal (Elsevier)
- Single anonymized review process (min 2 reviewers)

## Submission Format
- **Word limit: 3000 words** (short descriptive paper)
- Must use journal-specific LaTeX or Word template
- Must include open-source software distribution with support material
- The manuscript is an "accompanying note" for readers/users of the software

## Required Sections (from SoftwareX template)
1. **Motivation and significance** - Why the software exists, what problem it solves
2. **Software description** - Architecture, functionalities
   - Software architecture
   - Software functionalities
3. **Illustrative examples** - Demonstrations of use
4. **Impact** - Scientific/research impact
5. **Conclusions** - Summary

## Required Metadata Table
- Current software version
- Permanent link to code/repository
- Code Ocean compute capsule (if applicable)
- Legal software license
- Code versioning system
- Software code languages, tools, services
- Compilation requirements, dependencies
- Link to developer documentation/manual
- Support email for questions

## Review Criteria (what reviewers assess)
- Scientific relevance and impact
- Software quality and documentation
- Reproducibility
- Code availability and licensing
- Clarity of description

## Key Points for Acceptance
1. Software must be OPEN SOURCE
2. Code must be on a public repository (GitHub preferred - SoftwareX has its own GitHub)
3. Must demonstrate clear scientific impact
4. Must be well-documented
5. Must be reusable by others
6. 3000-word limit is strict - be concise
7. Focus on the SOFTWARE, not the science behind it
