   Issue: potentially misleading - SiliQun simulates 42 LOGICAL qubits (2^42 state vector),

          are similar in size! The 2^(2n) advantage is vs a hypothetical full-space simulation
          of 126 physical spins, not vs Osaka's actual simulation.
   Fix: CRITICAL - must clarify that the comparison is about what physical system each
        approach can represent, not about state vector sizes. SiliQun represents a LARGER
        physical system (126 spins) with a SIMILAR state vector size (2^42 vs 2^41).

KEY INSIGHT FROM VERITAS:
The comparison with Osaka must be carefully framed. Both approaches use similar
state vector sizes (~2^41 vs 2^42). The advantage of SiliQun is that it can
REPRESENT a much larger physical system (126 spins vs 41 qubits) because the
DFS projection compresses the representation. This is NOT the same as saying
SiliQun is 2^(2n) times faster or uses 2^(2n) less memory than Osaka.
