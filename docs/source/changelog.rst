Changelog
=========

v1.0.0 (2026-04-29)
--------------------

- Initial public release accompanying the SoftwareX submission
- Dual simulation backends: MPS tensor network + GPU state vector
- Silicon-specific device profiles: Donor, SiMOS, GAA, RIKEN 5Q
- DFS logical encoding with perturbative leakage tracking
- Native Gymnasium API for DRL integration (Stable-Baselines3, Ray RLlib, CleanRL)
- HPC job generation for PBS and SLURM schedulers
- SLEDGE grid topologies: 2x2, 3x3, 4x4, 5x5
- Benchmark suite: Bell state, GHZ state, W state
